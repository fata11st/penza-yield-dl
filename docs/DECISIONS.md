# Решения

Формат: дата — решение — причина — отвергнутые варианты.

**D1 · 29.10.2026 — отдельная машина WSL `penza-dl` и отдельный репозиторий.**
Причина: решение автора; проект не связан с `ml-lab` и toraX. Отвергнуто: вести как исследование в `ml-lab`.

**D2 · 29.10.2026 — PyTorch 2.14.1 + CUDA 13.0 (`cu130`), Python 3.12, менеджер окружений uv.**
Причина: RTX 5070 Ti требует сборок cu128+, cu128 выходил только до torch 2.11; та же версия проверена на `ml`.
Python 3.12 — системный в Ubuntu 24.04. Отвергнуто: cu128 (устаревшие версии torch), conda (медленнее, нет lock).

**D3 · 29.10.2026 — датасет `penza_dataset_2025.xlsx` хранится в репозитории, версия фиксируется SHA-256.**
Причина: 140 КБ открытых данных (Росстат/Пензастат, метеостанция WMO 27962, ERA5-Land, MODIS);
воспроизводимость без внешних шагов. SHA-256 `4b916c038d760c6d069078bd6b1a2d667c25547a7f4d7576eab98d522aad4b68`.

**D4 · 29.10.2026 — вложенная схема: подбор на 2011–2018, оценка на 2019–2025.**
Причина: в прошлых работах конфигурация Ridge выбиралась по тому же бэктесту, на котором оценивалась, —
оценка точности завышена. Все модели, включая эталоны, оцениваются по одной схеме.

**D5 · 29.10.2026 — пропуски не заполняются в загрузчике, а передаются маской.**
Причина: NDVI отсутствует до февраля 2000 г., ГТК/SAT — до 1994 г.; способ обработки — часть модели и
описывается в статье.

**D6 · 29.10.2026 — проект с нуля; результаты прошлых статей не воспроизводятся.**
Причина: код и JSON-конфигурации Ridge прошлых работ не сохранились (решение автора). Точка отсчёта — новые эталоны E01
(наивный прогноз, линейный тренд, Ridge с небольшой сеткой) по той же вложенной схеме, что и нейросети. В статье прошлые
работы упоминаются как предшествующие, без прямого сравнения чисел. Отвергнуто: восстанавливать прежнюю методику по
тексту статей (риск получить другие числа и неясное происхождение конфигураций).

**D7 · 29.10.2026 — E01: постановка «прогноз по окончании вегетации», признаки текущего сезона.**
Признаки: лаги и скользящее среднее собственной урожайности (только прошлые годы), тренд, температура и осадки
метеостанции, влажность почвы и испаряемость ERA5-Land, NDVI (набор с NDVI обучается с 2000 г.). Внутрисезонная
постановка (данные до месяца отсечки) — в следующих экспериментах с нейросетями.

**D8 · 29.10.2026 — основное сравнение моделей — по всем культурам вместе (до результатов нейросетей).**
Причина: E01 показал, что на 7 годах оценки тест Диболда–Мариано не различает даже эталоны (все p > 0,1), а средний
MAPE культуры определяют один-два года (засуха 2024 г., подсолнечник 2019–2020 гг.). Правила:
главная метрика — MAPE по 35 прогнозам (5 культур × 2019–2025) с 95% бутстреп-интервалом, где переотбираются годы
целиком (ошибки культур одного года связаны погодой); сравнение — парный тест DM (h = 1, поправка HLN) по тем же 35
прогнозам; по каждой культуре — MAPE, медиана и максимум APE. Честный эталон для сравнения — «эталон, выбранный на
2011–2018»: для каждой культуры та из трёх моделей E01, что лучше на годах подбора. Лучший эталон по годам оценки —
только ориентир. Зафиксировано до первого запуска нейросетей. Отвергнуто: сравнение по каждой культуре отдельно как
основное (нет статистической силы); удлинение годов оценки (меняет уже зафиксированный протокол D4).

**D9 · 29.10.2026 — E02: многозадачная GRU, внутрисезонный прогноз.**
Вход: аномалии 16 помесячных переменных до месяца отсечки (норма и разброс месяца — по окну обучения), канал наличия
NDVI, log(lag1/ma3), log(lag2/ma3) пяти культур, нормированный год. Выход: log(y/ma3) пяти культур сразу,
ŷ = ma3 · exp(r̂). GRU с одним слоем, dropout 0,2, AdamW, шум 0,1 на входе, обучение всей выборкой фиксированное число
эпох. Сетка: скрытый слой {8, 16} × weight decay {1e-3, 1e-2, 1e-1} × эпохи {100, 300}; конфигурация выбирается
для каждого месяца отсечки по объединённому MAPE на 2011–2018 (10 seed), итоговые прогнозы — ансамбль 20 seed.
Отсечки: конец июня, июля, августа, сентября. Причины: цель log(y/ma3) убирает масштаб культур и уровень, оставляя
модели отклонение от недавней нормы; многозадачность даёт 5 целей на год; расчёт на CPU — модели крошечные, на GPU
накладные расходы больше вычислений. Отвергнуто: ранняя остановка по внутренней проверке (на 20–30 годах
отщеплённая проверка слишком мала и шумна), отдельная модель на культуру (в 5 раз меньше целей).

**D10 · 30.10.2026 — ночная очередь E03–E07; дизайн и критерии зафиксированы до запуска.**
Основание — разбор E02 только на годах подбора 2011–2018: якорь ma3 сам по себе (21,5%) точнее, чем GRU E02 с ним
(22,5–27,9%), а с сентябрём хуже, чем с августом. Диагноз — подстройка под шум (16 переменных × до 9 месяцев на 20–25 лет),
а не неудачный якорь: тренд как якорь на годах подбора не лучше (20,7%). Годы 2019–2025 для решений не использовались.
Эксперименты:
- E03 — GRU, 4 переменные (температура, осадки, влажность почвы 7–28 см, NDVI), скрытый слой {4, 8} × weight decay
  {0,01; 0,1; 1} × эпохи {30, 100}; отсечки июнь…сентябрь; подбор и ансамбли как в D9.
- E04 — то же с 1D-CNN (свёртка по месяцам, окно 3; среднее и последний месяц).
- E05 — MLP (один скрытый слой {4, 16}, tanh, L2 {0,1; 1; 10}, L-BFGS) на годовых признаках ar_climate, по культурам,
  цель log(y/ma3); одна конфигурация на все культуры по объединённому MAPE 2011–2018.
- E06 — TabPFN на ar_climate_ndvi, по культурам, цель log(y/ma3), без подбора, среднее 3 seed. Требует TABPFN_TOKEN.
- E07 — Chronos-2 (amazon/chronos-2) без дообучения, медиана; варианты: только ряд, + погода сезона как известные
  ковариаты (основной), + совместный прогноз пяти культур.
Критерии: (1) модель полезна, только если на годах подбора точнее якоря ma3; для моделей с подбором это необходимое,
но не достаточное условие (MAPE подбора у них оптимистичен); (2) главное сравнение — по D8, с «эталоном, выбранным на
2011–2018» и с якорем. Якорь ma3 добавлен во все таблицы как эталон. Все эксперименты публикуются независимо от
результата; E02 остаётся в статье как есть.

**D11 · 30.10.2026 — панель 10 регионов; протокол, очистка и признаки зафиксированы до первых расчётов на панели.**
Данные: Пензенская обл. + 9 регионов (Саратовская, Ульяновская, Тамбовская, Самарская, Нижегородская, Рязанская обл.,
Мордовия, Татарстан, Чувашия), собраны автором по структуре пензенского датасета (`data/raw/regions/`, SHA-256 в
`panel.py`). Аудит перед использованием выявил и закрепил правила:
- целевые значения не заполняются; урожайность исключается при площади < 1 тыс. га (68 случаев: свёкла в Самаре и
  Чувашии и т. п.) и при служебных значениях площади/сбора ≥ 1e6 (Чувашия, свёкла 2021: 999999999);
- NDVI — только MODIS, с февраля 2000 г.: GIMMS 1990-х во всех 9 регионах выше MODIS 2000-х на 0,04–0,07 (смена
  прибора, а не растительности); пропуски NDVI в зимних месяцах не заполняются (в признаках не участвуют);
- потенциальная испаряемость ERA5 приведена к положительному знаку (в пензенском файле — соглашение ERA5, минус);
- лист «Вегетация_GTK» в панели не используется: испаряемость Пензы (метод Мезенцева, ~180 мм) и остальных регионов
  (EVPTRNS, ~350–590 мм) несопоставимы; вместо них 16 агрономических признаков (`panel.ENG_FEATURES`), одинаково
  посчитанных для всех регионов из помесячных рядов до сентября: тепло мая–июня и июля–августа, максимумы июля–августа,
  осадки апреля–мая, июня, июля–августа, ГТК Селянинова за май–август по месяцам, водный баланс (осадки ERA5 − PET),
  влагозапас почвы в апреле (0,07–0,28 и 0,28–1 м) и июле, максимальный запас воды в снеге (декабрь–март), минимум
  температуры почвы январь–февраль, радиация июня–августа, NDVI мая и пик июня–августа;
- все погодные признаки подаются моделям как аномалии внутри региона (норма — по окну обучения): источники
  станционного климата различаются (станции, NASA POWER у Ульяновской обл. и Чувашии).
Протокол:
- годы прогнозов 2006–2025: 2006–2010 — разгон (только для весов ансамблей), 2011–2018 — подбор, 2019–2025 — оценка;
  окно обучения расширяется, панельные модели учатся на всех регионах по годам < t;
- **основная оценка — 9 новых регионов, 2019–2025** (291 прогноз; эти годы не участвовали ни в каких решениях);
  Пенза 2019–2025 — вторичная оценка (её годы уже просмотрены в E01–E07);
- прогнозируются только ряды, где известны урожайность года и три предыдущих года (общий набор для всех моделей);
- метрики по D8: MAPE, бутстреп с переотбором лет целиком, парный DM; эталон — «эталон, выбранный на 2011–2018» среди
  наивного, тренда и якоря (для каждой культуры), плюс якорь ma3.
Модели (подбор гиперпараметров — по объединённому MAPE всех регионов на 2011–2018):
- P-эталоны: наивный, линейный тренд ряда, якорь ma3;
- P-Ridge: по культуре на всех регионах; признаки {лаги; лаги + агропризнаки} × α {0,1; 1; 10; 100; 1000};
- P-GBM (LightGBM): по культуре; листьев {4, 8} × деревьев {100, 300}, шаг 0,05, 5 seed;
- P-MLP: одна сеть на все культуры (one-hot культуры и региона); скрытый слой {16, 64} × wd {1e-3; 1e-2; 1e-1} ×
  эпохи {200, 500}; 10/20 seed;
- P-GRU: последовательности 8 переменных, январь–сентябрь, аномалии месяца в регионе + лаги 5 культур, 5 выходов с
  маской; скрытый слой {8, 16, 32} × wd {1e-3; 1e-2; 1e-1} × эпохи {100, 300}; 10/20 seed;
- P-Chronos-2: без дообучения, совместный прогноз всех рядов года (cross_learning); ряд и ряд + агропризнаки (без NDVI)
  как известные ковариаты; контекст — непрерывный участок ряда до t−1 (≥ 8 лет), иначе прогноз якоря (число случаев
  сообщается).
Ансамбли — для каждой культуры, только по прогнозам прошлых лет (с 2006 г.), состав компонентов фиксирован (все модели
выше): среднее; медиана; среднее нейросетевых (MLP, GRU, Chronos-2 с ковариатами); веса ∝ 1/MAPE прошлых лет;
стекинг — неотрицательные веса с суммой 1 по МНК в лог-шкале на прошлых годах; выбор лучшей модели по прошлым годам.
Вторично: Пенза; разбивка по культурам. Все результаты публикуются независимо от исхода.

**D12 · 30.10.2026 — итог панели P01–P03 (запись результата, не решение о протоколе).**
Источник: `experiments/P03-summary/summary.csv`, `mape_eval_new_by_region.csv`. Основная оценка — 9 новых регионов,
2019–2025, 291 прогноз. Лучший результат — ансамбль нейросетей (MLP, GRU, Chronos-2 с ковариатами): MAPE 12,74%
[11,19; 14,62] против 14,47% [12,41; 16,41] у эталона, выбранного на 2011–2018; DM по прогнозам p = 0,002, консервативный
DM по годовым средним (n = 7) p = 0,137. Ансамбли «среднее», «1/MAPE», «стекинг» — 12,90–13,04%, p ≤ 0,01 по прогнозам,
p = 0,058–0,071 по годам. Ни одна отдельная модель значимо не лучше эталона (LightGBM 13,67%, p = 0,24). Ансамбль
нейросетей точнее эталона в 8 из 9 регионов и точнее якоря в 5 из 7 лет. Ridge при подборе выбрал только лаги (α = 1000):
линейной модели агропризнаки не помогли. Chronos-2: 33 прогноза из ~900 заменены якорем (ряды с разрывами).
Пенза (вторично): ансамбль нейросетей 12,54%, LightGBM 11,61%, эталон 12,83%.
Вывод для статьи: выигрыш даёт объединение прогнозов разных моделей, обученных на панели, а не отдельная архитектура.
