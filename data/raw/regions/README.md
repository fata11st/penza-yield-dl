# Данные 9 регионов

Собраны автором по структуре пензенского датасета (описание источников и методики — `README_source.md`).
Версии фиксируются SHA-256 в `src/penza_yield/panel.py`. Правила очистки при загрузке — решение D11
(`docs/DECISIONS.md`): исключение площадей < 1 тыс. га и служебных значений, NDVI только MODIS (с февраля 2000 г.),
положительный знак PET, агрономические признаки пересчитываются одинаково для всех регионов.

Известные особенности (аудит 30.10.2026): Чувашия, свёкла 2021 — служебное значение площади 999999999;
NDVI 1990-х (GIMMS) выше MODIS на 0,04–0,07; климат Ульяновской обл. и Чувашии — NASA POWER (станционные ряды неполны);
лист «Вегетация_GTK» посчитан иначе, чем у Пензы (испаряемость EVPTRNS против метода Мезенцева).
