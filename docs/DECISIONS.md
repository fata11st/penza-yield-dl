# Решения

Формат: дата — решение — причина — отвергнутые варианты.

**D1 · 29.10.2026 — отдельная машина WSL `penza-dl` и отдельный репозиторий.**
Причина: решение автора; проект не связан с `ml-lab` и toraX. Отвергнуто: вести как исследование в `ml-lab`.

**D2 · 29.10.2026 — PyTorch 2.14.1 + CUDA 13.0 (`cu130`), Python 3.12, менеджер окружений uv.**
Причина: RTX 5070 Ti требует сборок cu128+, cu128 выходил только до torch 2.11; та же версия проверена на `ml`.
Python 3.12 — системный в Ubuntu 24.04. Отвергнуто: cu128 (устаревшие версии torch), conda (медленнее, нет lock).

**D3 · 29.10.2026 — датасет `penza_dataset_2025.xlsx` хранится в репозитории, версия фиксируется SHA-256.**
Причина: 140 КБ открытых данных (Росстат/Пензастат, метеостанция WMO 27962, ERA5-Land, MODIS);
воспроизводимость без внешних шагов. SHA-256 `4b916c038d760c6d069078bd6b1a2d667c25547a7f4d7576eab98d522aad4b68`.

**D4 · 29.10.2026 — вложенная схема: подбор на 2011–2018, оценка на 2019–2025.**
Причина: в прошлых работах конфигурация Ridge выбиралась по тому же бэктесту, на котором оценивалась, —
оценка точности завышена. Все модели, включая эталоны, оцениваются по одной схеме.

**D5 · 29.10.2026 — пропуски не заполняются в загрузчике, а передаются маской.**
Причина: NDVI отсутствует до февраля 2000 г., ГТК/SAT — до 1994 г.; способ обработки — часть модели и
описывается в статье.

**D6 · 29.10.2026 — проект с нуля; результаты прошлых статей не воспроизводятся.**
Причина: код и JSON-конфигурации Ridge прошлых работ не сохранились (решение автора). Точка отсчёта — новые эталоны E01
(наивный прогноз, линейный тренд, Ridge с небольшой сеткой) по той же вложенной схеме, что и нейросети. В статье прошлые
работы упоминаются как предшествующие, без прямого сравнения чисел. Отвергнуто: восстанавливать прежнюю методику по
тексту статей (риск получить другие числа и неясное происхождение конфигураций).

**D7 · 29.10.2026 — E01: постановка «прогноз по окончании вегетации», признаки текущего сезона.**
Признаки: лаги и скользящее среднее собственной урожайности (только прошлые годы), тренд, температура и осадки
метеостанции, влажность почвы и испаряемость ERA5-Land, NDVI (набор с NDVI обучается с 2000 г.). Внутрисезонная
постановка (данные до месяца отсечки) — в следующих экспериментах с нейросетями.
