# План работы

## Научная новизна

Ridge-методика из прошлых статей работает на годовых агрегатах. Глубокое обучение на 36 строках таблицы почти
наверняка ей проиграет, поэтому акцент — там, где у DL есть реальное преимущество:

1. **Внутрисезонный прогноз** на помесячных последовательностях: прогноз «по состоянию на» 1 июня, 1 июля,
   1 августа. Кривая «точность от месяца отсечки» — главный результат.
2. **Многозадачное обучение**: общий энкодер сезона и пять выходов (36 × 5 целевых значений вместо 36).
3. **Предобученные модели для малых данных**: TabPFN (таблицы), Chronos / TimesFM (ряды).
4. **Честное сравнение**: вложенная схема, точные значения (без «~»), тест Диболда–Мариано, несколько seed.

Проигрыш DL на годовых данных — тоже результат: граница применимости по объёму выборки.

## Модели

| Группа | Модели | Вход |
|---|---|---|
| Эталоны | Ridge (конфигурации из прошлых работ), наивный lag1, тренд | годовой |
| Табличные DL | MLP с dropout и weight decay, TabPFN | годовой |
| Последовательностные | LSTM / GRU, 1D-CNN / TCN, малый Transformer | помесячный 12 × 16 |
| Гибриды | Ridge + NN на остатках; CNN-энкодер сезона → Ridge-голова | оба |
| Многозадачные | общий энкодер + 5 голов | помесячный |
| Предобученные | Chronos, TimesFM (zero-shot и дообучение) | ряд урожайности (+ковариаты) |

Для малой выборки: ансамбль 10–20 seed, ранняя остановка по внутреннему окну, сильная регуляризация,
аугментация (бутстреп лет, mixup, шум погоды), маски пропусков (NDVI до 2000 г.).

## Протокол

- Расширяющееся окно, одношаговые прогнозы 2011–2025; MAPE, RMSE, MAE.
- **Вложенная схема**: подбор гиперпараметров на 2011–2018, итоговая оценка — 2019–2025. Ridge — по той же схеме
  (в прошлых работах сеточный поиск 12–25 тыс. конфигураций шёл по тем же годам, что и оценка, — оценка завышена).
- Диболд–Мариано для пар моделей, бутстреп-интервалы для MAPE.
- Абляции: без NDVI, без ERA5, одно- и многозадачная, месяц отсечки (июнь / июль / август).
- Интерпретация: integrated gradients / attention по месяцам.
