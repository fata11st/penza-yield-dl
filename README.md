# penza-yield-dl

Прогнозирование урожайности пяти сельскохозяйственных культур Пензенской области (1990–2025) методами глубокого
обучения и сравнение с эталонами (наивный прогноз, тренд, Ridge). Цель — статья уровня ВАК (8–10 страниц).

Предыдущие работы на этом же датасете (результаты не воспроизводятся, проект с нуля — D6):
1. Тишин М.Е., Дубинин А.В. Методологический подход к прогнозированию урожайности сельскохозяйственных культур
   на основе Ridge-регрессии (на примере Пензенской области) // Сурский вестник. 2026. № 2 (35). С. 75–81.
   DOI 10.36461/2619-1202_2026_02_012.
2. Дубинин А.В., Тишин М.Е., Федотова М.Ю. // Московский экономический журнал. 2026. № 5.

План работы — [`docs/PLAN.md`](docs/PLAN.md), окружение — [`docs/ENVIRONMENT.md`](docs/ENVIRONMENT.md),
решения — [`docs/DECISIONS.md`](docs/DECISIONS.md).

## Структура

```
configs/resources.yaml   лимиты CPU/памяти/GPU и свободные порты (машина WSL общая)
data/raw/                датасет (версия фиксируется SHA-256 в src/penza_yield/data.py)
src/penza_yield/
  data.py                годовая таблица и помесячный тензор [год, месяц, переменная] с маской пропусков
  features.py            годовые признаки эталонов (лаги, тренд, погода сезона, NDVI)
  baselines.py           наивный прогноз, тренд, Ridge
  seqmodel.py            многозадачная GRU на помесячных данных (E02)
  meta.py                метаданные запуска (коммит, версии, GPU, хеш датасета)
  validation.py          расширяющееся окно, вложенная схема (подбор 2011–2018, оценка 2019–2025)
  metrics.py             MAPE, RMSE, MAE, тест Диболда–Мариано, бутстреп по годам
  resources.py           применение лимитов ресурсов
scripts/                 запуски экспериментов
tools/                   проверка GPU, метаданные запуска, запуск с лимитом памяти
tests/                   проверки данных и отсутствия утечки из будущего
experiments/             результаты запусков (в git — только метрики и графики)
paper/                   текст статьи, рисунки, таблицы
```

## Эксперименты

| Код | Что | Скрипт |
|---|---|---|
| E01 | Эталоны: наивный, тренд, Ridge по вложенной схеме | `scripts/e01_baselines.py` |
| E02 | Многозадачная GRU, внутрисезонный прогноз (июнь…сентябрь) | `scripts/e02_gru_inseason.py` |

## Правила

- Каждый запуск сохраняет `meta.json` (`penza_yield.meta.collect`): коммит, seed, версии, GPU, хеш датасета.
- Числа в статье — только из файлов в `experiments/`, с путём к файлу.
- Масштабирование, отбор признаков и подбор гиперпараметров — строго внутри окна обучения.
- Годы 2019–2025 не участвуют в подборе чего-либо.
